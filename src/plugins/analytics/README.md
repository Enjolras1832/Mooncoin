# Analytics

Privacy-friendly analytics: Plausible, Umami, or GoatCounter.

A plugin for [Digital Garden](https://github.com/oleeskild/digitalgarden) sites.

## Install

Paste this repo's URL into **Settings → Digital Garden → Plugins → Install from GitHub** in Obsidian, or copy this folder into `src/plugins/analytics/` in your garden repo.

## Settings

- **Provider** — Which analytics service to load.
- **Site ID** — Plausible: your domain. Umami: the website ID. GoatCounter: your code (the part before .goatcounter.com).
- **Custom script URL** — Optional, for self-hosted instances. Leave empty for the provider's default.
